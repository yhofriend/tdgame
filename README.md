# 暮光军团 · Twilight Legion（试玩版）

军团战争式（Legion-TD-like）1v1 对战塔防，浏览器里直接玩，不用安装。

**在线试玩：** https://yhofriend.github.io/tdgame/

- 电脑用 Chrome 或 Edge 打开最好。手机、平板也能玩（横屏、竖屏都可以，双指缩放），但还没在真机上大量测试，体验以电脑为准。
- 有显卡加速时是 3D 画面；没有时会自动换成 2D 画面（同一批模型预先渲染），开局时会提示一次。设置里的「画面」可以手动切换，「画质」调低会更流畅。
- 第一次打开要下载几十 MB 资源，请等进度条走完。
- 离线版：在 [Releases](https://github.com/yhofriend/tdgame/releases/latest) 下载 `twilight-legion.html`（约 60 MB），双击用 Chrome 或 Edge 打开，不需要联网。目前 Releases 里的离线文件还是 0.2 版（旧规则），在线版已经是 0.3。

## 怎么玩

备战阶段在自己的路线上摆兵、升级、合成，只用金币（每波收入加上本路的击杀赏金）。开战后暮生者从裂隙涌出，漏过防线的怪会去打你的王座，王座的圣坛会反击。谁的王座先倒下谁输；打完 20 波还没分出胜负，再来最多 3 波「暮光潮汐」，之后比王座剩余血量。第一局有新手引导。

0.3 版是精简规则的测试版：去掉了第二种资源、工人、国王升级、战术卡、秘契和佣兵，派兵会在之后的版本里以兵营的形式回来。
